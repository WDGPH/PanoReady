# Support

Use [GitHub Issues](https://github.com/WDGPH/PanoReady/issues) for reproducible bugs and focused feature requests. Before opening an issue:

1. Review the [documentation](https://wdgph.github.io/PanoReady/docs/).
2. Search existing issues for the same problem.
3. Reproduce the issue with synthetic data.

PanoReady is open-source software provided without warranty or a guaranteed response time. The public issue tracker is not an appropriate channel for operational emergencies, organization-specific support, or questions containing student records or other sensitive information.

Report suspected security vulnerabilities privately according to [SECURITY.md](SECURITY.md).
