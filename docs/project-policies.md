# Project policies

The canonical policy files live in the repository root:

- [Contributing](https://github.com/WDGPH/PanoReady/blob/main/CONTRIBUTING.md) explains how to propose, implement, test, and document a change.
- [Code of Conduct](https://github.com/WDGPH/PanoReady/blob/main/CODE_OF_CONDUCT.md) defines expected community behaviour and reporting.
- [Security Policy](https://github.com/WDGPH/PanoReady/blob/main/SECURITY.md) explains private vulnerability reporting and the supported version.
- [MIT License](https://github.com/WDGPH/PanoReady/blob/main/LICENSE) grants permission to use, modify, and distribute the project under its terms.

## Support

Review this documentation and search [existing issues](https://github.com/WDGPH/PanoReady/issues) before reporting a reproducible problem. Use synthetic data only. Public issues must never contain student records, personal information, credentials, or other sensitive information.

Open-source maintenance is provided without a guaranteed response time. Security vulnerabilities belong in [private vulnerability reporting](https://github.com/WDGPH/PanoReady/security/advisories/new), not the public issue tracker.
